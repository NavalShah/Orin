# Raga to Keys

A Next.js app for exploring a Carnatic-inspired melody as a piano sketch. The interface pairs a simple sargam phrase with synthesized playback, an editable piano sketch, and short musical context.

## Run it

Install dependencies with `npm install`, then start the development server with `npm run dev` and open the local URL shown in the terminal. Use `npm run build` to create a production build.

The browser needs Web Audio support for playback. Start playback or press a piano key once to enable audio.

## Scope

The example is a representative learning sketch, not an audio transcription or a claim to represent a particular raga. The prototype does not analyze uploaded recordings, infer tala, produce staff notation, or create an expressive audio arrangement. Those features need a transcription pipeline and review with a Carnatic musician.
